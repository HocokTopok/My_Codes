# Ответы для ведущего

## Сломай проверку пароля — `Password.cpp`

1. **Ошибочно принятый пароль.** Например, `A`: он слишком короткий и не содержит цифры, но `has_upper` равен `true`, поэтому правая часть `||` разрешает доступ. Другой пример — `12345678`: выполнена левая часть, хотя заглавной буквы нет.
2. **Исправление и проверка.** Все три требования должны выполняться одновременно, поэтому в отмеченной строке используем `&&`:

```cpp
return password.size() >= 8 && has_digit && has_upper;
```

После исправления пересобрать программу и проверить:

| Пароль | Ожидаемый результат | Причина |
|---|---|---|
| `A` | ДОСТУП ЗАПРЕЩЁН | Найденный обход больше не работает |
| `Abcdefg1` | ДОСТУП РАЗРЕШЁН | Все требования выполнены |
| `Abcdef1` | ДОСТУП ЗАПРЕЩЁН | Меньше 8 символов |
| `Abcdefgh` | ДОСТУП ЗАПРЕЩЁН | Нет цифры |
| `abcdefg1` | ДОСТУП ЗАПРЕЩЁН | Нет заглавной латинской буквы |

## Одна правка — `OneLine.cpp`

```cpp
double average = static_cast<double>(sum) / count;
```

Изначально оба операнда целые, поэтому дробная часть теряется до записи в `double`. Преобразовать нужно операнд **до** деления. Вариант `static_cast<double>(sum / count)` ошибку не исправляет. Возможен также ответ `double average = 1.0 * sum / count;`.

## Сейф — `Safe.cpp`

Все подходящие ключи:

- `063099`
- `162198`
- `261297`
- `360396`

Ключ содержит шесть цифр, их сумма — 27, сумма первой и последней — 9, а правая тройка как число на 36 больше левой. Например, для `063099`: сумма цифр `0 + 6 + 3 + 0 + 9 + 9 = 27`, крайние цифры дают `9`, половины — `63` и `99`.

Решение без перебора: попробуем прибавление 36 без переносов. Тогда ключ имеет вид `a b c | a (b + 3) (c + 6)`.

- Из суммы цифр: `2(a + b + c) + 9 = 27`, значит `a + b + c = 9`.
- Из суммы крайних цифр: `a + c + 6 = 9`, значит `a + c = 3`.
- Следовательно, `b = 6`. Выбираем `(a, c)` из `(0, 3)`, `(1, 2)`, `(2, 1)`, `(3, 0)` и получаем ключи выше. Переносов действительно нет: `b + 3 = 9`, а `c + 6 ≤ 9`.

## Серия без повторов — `UniqueRun.cpp`

Заменить первую функцию целиком:

```cpp
std::size_t FastUniqueRun(const std::vector<int>& values)
{
  size_t seen[256]{};

  size_t left = 0;
  size_t right = 0;

  size_t max_len = 0;

  while (right < values.size()) {
    int new_element = values[right];

    left = std::max(left, seen[new_element]);

    seen[new_element] = right + 1;

    max_len = std::max(max_len, right - left + 1);

    ++right;
  }

  return max_len;
}
```

Поддерживаем окно `[left, right]` без повторов. В `seen[new_element]` хранится позиция сразу после последнего появления значения; ноль означает, что его ещё не было. Встретив повтор, сдвигаем левую границу за предыдущее появление. `std::max` не позволяет границе двигаться назад, если старое появление уже за пределами окна.

Готовая медленная функция перебирает все начала и все окончания, даже после обнаружения повтора: время `O(n²)`. Быстрая проходит массив один раз: время `O(n + 256)`, дополнительная память `O(256)`. Благодаря фиксированному диапазону значений не нужна хеш-таблица. Просто остановить внутренний цикл медленного решения после повтора тоже ускоряет его и при данном алфавите ограничивает просмотр 256 различными значениями; приведённое решение дополнительно устраняет повторные проходы.

После вставки решения все тесты должны пройти. Затем программа сравнит время на одинаковых входах. Проценты вычисляются из средних времён пяти повторений, а не усредняются между размерами. Ускорение не является проверкой корректности: сначала обязательно проходят тесты.
